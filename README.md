# dithernaut tap

## formulae

  - [`repixel`](https://github.com/dithernaut/repixel): CLI tool for recoloring and rescaling still and animated pixel art images.
  - [`shimmy`](https://github.com/dithernaut/shimmy): untracked AI-tool-specific Markdown symlinks to repo agent instructions

## casks

  - [`quanta-strike-fonts`](https://github.com/dithernaut/quanta-strike): Pixel typeface with multiple strikes
  - [`quanta-strike-fonts-nerd`](https://github.com/dithernaut/quanta-strike): Nerd fonts patched versions of the monspacte quanta-strike fonts

## Install formulae/casks

*formulae:*
```sh
brew install dithernaut/tap/<formula>
```

*casks:*
```sh
brew install --cask dithernaut/tap/<cask>
```

Or `brew tap dithernaut/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "dithernaut/tap"
brew "<formula>"
```
